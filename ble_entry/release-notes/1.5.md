Optional app updates from GitHub Releases.

- Door checks for updates when opened, at most once every six hours.
- Choose Update, Later, or Skip this version. Automatic checks can be disabled.
- Downloaded APKs must match the expected checksum, app identity, version and signing certificate.
- Android asks before installation; enrollment and calibration stay saved.
- Includes the bottom proximity cards, minimize/expand controls, and background BLE testing from 1.4.

This remains a dry run. Real door operation and TOTP delivery are disabled; face/button entry remains an animation preview. Internet access is used for GitHub app updates only.

On 1.4 or earlier, install this APK once without uninstalling the existing BLE app. Future updates can then be offered inside Door.
